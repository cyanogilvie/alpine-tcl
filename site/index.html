cftcl

A batteries-included Tcl 9 runtime with rl_json, tomcrypt, aws, parsetcl and friends — packaged for direct apk add install on Alpine.

Install on Alpine

Run as root inside an Alpine 3.23+ container or host (the repo uses the apk-v3 index format, so apk-tools 3 is required — note the v3 prefix on the repositories line):

wget -qO /etc/apk/keys/cftcl.rsa.pub https://cftcl.cyanogilvie.com/alpine/v1/keys/cftcl.rsa.pub
echo "v3 https://cftcl.cyanogilvie.com/alpine/v1" >> /etc/apk/repositories
apk update
apk add cftcl

The Tcl runtime installs under /opt/cftcl; the shell is /opt/cftcl/bin/tclsh.

Quick smoke test

/opt/cftcl/bin/tclsh <<'EOF'
package require rl_json
namespace import ::rl_json::json
puts [json pretty {{"hello":"world"}}]
EOF

Sub-packages

The base cftcl package gives you a working Tcl interpreter with most batteries already loaded. The split-off sub-packages are optional:

PackageContents
cftclMain runtime — Tcl 9, rl_json, tomcrypt, aws, parsetcl, tcllib, etc.
cftcl-devBuild headers, stubs library, pkg-config files. Install to compile C extensions against this Tcl.
cftcl-docMan pages and reference docs.
cftcl-svgPixel_svg_cairo (SVG rendering via cairo). Pulls in cairo + rsvg.
cftcl-phashPixel_phash perceptual-hash extension.
cftcl-dbgDetached debug symbols (large; for gdb / valgrind).

Architectures

Builds are published per architecture under /alpine/v1/<arch>/. Currently available:

  • x86_64
  • aarch64
